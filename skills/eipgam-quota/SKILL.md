---
name: eipgam-quota
description: Check eipgam subscription allowances, usage windows, reset times, and API key balances.
---

Run `eipgam quota` and summarize the plans and windows it reports.
Distinguish percent used from percent remaining and include the reset time
when available. Preserve any stale or unavailable status from the CLI.
Use `eipgam quota --help` to see the supported filters and refresh options.
