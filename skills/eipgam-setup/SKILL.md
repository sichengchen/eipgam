---
name: eipgam-setup
description: Configure the eipgam gateway, providers, agent model picks, routing groups, and gateway keys through its CLI.
---

Run `eipgam --version` and `eipgam help` to confirm the installed commands.
Read the current setup with `eipgam status`, `eipgam list`, and
`eipgam providers` before making changes. Use the command help to discover
provider presets, agent model IDs, and routing options supported by this build.

Apply only the requested changes. Use sign-in prompts for subscription
accounts and keep credentials out of replies. Read the affected configuration
back through the CLI to verify the result.
